**Orkesta** merupakan aplikasi produktivitas untuk developer di Windows. Todo, riwayat clipboard, timer fokus, pengingat, kirim file, dan alat bantu kerja developer tersedia dalam satu aplikasi. Hampir semuanya bisa dibuka dari notch kecil di bagian atas layar, tanpa perlu berpindah jendela.

## Cara pasang

Unduh `Orkesta-Setup-0.1.0-x64.exe`, lalu jalankan. Saat instalasi, Anda bisa memilih fitur yang ingin ditampilkan dan apakah Orkesta langsung berjalan saat komputer dinyalakan.

## Notch di bagian atas layar

Notch tampil di bagian atas layar dan mengecil menjadi garis tipis saat Anda sedang bekerja. Arahkan kursor ke sana untuk melihat todo hari ini, isi clipboard terakhir, jadwal sholat, dan timer fokus. Untuk mengirim file, cukup tarik file ke notch.

Tampilan notch bisa dibuat lebih transparan lewat Pengaturan.

## Todo

- Catat pekerjaan dalam bentuk kartu, lengkap dengan catatan, tanda favorit, dan tenggat waktu.
- Todo yang terlambat atau jatuh tempo hari ini selalu muncul di notch dan bisa langsung dicentang dari sana.

## Riwayat clipboard

Orkesta menyimpan 50 teks atau gambar terakhir yang Anda salin. Tekan **Win+Alt+V** untuk membukanya, lalu klik salah satu item untuk menyalinnya lagi. Password yang disalin dari password manager tidak ikut disimpan.

## Fokus dan pengingat

- Timer fokus 25, 45, atau 50 menit, atau durasi pilihan sendiri, diikuti istirahat 5 menit.
- Pengingat untuk mengistirahatkan mata, minum air, dan peregangan.
- Jadwal sholat dengan hitung mundur dan pengingat yang muncul kembali sampai Anda menandai sudah sholat. Lokasi bisa disesuaikan.

## Kirim file

- Kirim file ke komputer lain yang juga memakai Orkesta, selama masih terhubung ke Wi-Fi atau jaringan kantor yang sama.
- Kirim dan terima file dari HP cukup dengan memindai QR code. HP tidak perlu memasang aplikasi.
- File dikirim langsung antarperangkat, tidak melewati internet, dan setiap file masuk harus Anda setujui terlebih dahulu.

Fitur ini perlu dinyalakan dulu lewat **Pengaturan > Transfer file**.

## Alat bantu developer

- Mencoba endpoint API, termasuk mengimpor request dari browser.
- Load test sederhana untuk melihat ketahanan layanan saat diakses banyak pengguna.
- Pemeriksaan koneksi jaringan, seperti Ping dan cek port.

## Lainnya

- Orkesta bisa tetap berjalan di latar belakang setelah jendelanya ditutup, dan dibuka kembali dari ikon di taskbar.
- Pembaruan aplikasi bisa diperiksa dan dipasang langsung dari dalam Orkesta.
- Tersedia dalam bahasa Indonesia dan Inggris, dengan mode terang dan gelap.

## Catatan

- Orkesta saat ini hanya tersedia untuk Windows.
- Jadwal sholat memerlukan koneksi internet.
- Kirim file ke HP sebaiknya dilakukan di jaringan yang Anda percaya, seperti jaringan rumah atau kantor.
- Pengiriman folder belum didukung. Kirim isi folder sebagai beberapa file.
